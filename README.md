# Akhil Gujarat

Akhil Gujarat is a modern, full-stack Next.js 16 news portal built with Supabase and Backblaze B2.

## Documentation

The authoritative single source of truth for all architectural, operational, and deployment information is located at:
**[docs/PROJECT.md](./docs/PROJECT.md)**

## Quick Start

1. Copy `.env.example` to `.env.local` and configure your credentials.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
