# Ads v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the ads system with 4 display frames, optional links, 5 new placement slots, and article-style admin actions.

**Architecture:** Extends the existing ads feature (constants in `src/lib/ads.ts`, `Ad` type, `adSchema`, `AdBanner` server component, `/admin/ads` page). Frames are aspect-ratio boxes rendered by `AdBanner`; `link_url` blank renders static. New slots are additional `AD_SLOTS` keys wired into homepage/search/article pages. No new dependencies.

**Tech Stack:** Next.js 16.3.1 App Router, TypeScript, Tailwind v4, zod, vitest, SWR.

**Spec:** `docs/superpowers/specs/2026-08-20-ads-v2-design.md` (approved)

## Global Constraints

- No new dependencies, no new env vars.
- `Ad` type in `src/lib/types.ts` keeps `frame: string` (do NOT import from `src/lib/ads.ts` into types.ts — avoids a types→ads import cycle; `adSchema` constrains the value).
- Tuple-cast pattern for enum key arrays: `readonly [string, ...string[]]` via `as unknown as readonly [string, ...string[]]` (direct assignment of `.map()` fails TS2322 — use the existing `AD_SLOT_KEYS` line as the model).
- Bilingual labels everywhere: `t('ગુજરાતી', 'English')` via `useAdminLang` in client components; literal `labelGu`/`labelEn` in constants.
- Baseline verification (all tasks inherit): `npx tsc --noEmit` clean; `npm run lint` 0 errors / 6 pre-existing warnings; `npm test` 35 passing.
- DB migration is USER-RUN (Supabase MCP unavailable) — no migration code in tasks; the SQL is in Task 7.
- Do not touch: `getAdsForSlot`, `app/api/ads/route.ts`, share buttons, NewsCard, upload route.

- [ ] **Step 1: Rewrite AdBanner.tsx**

Replace the entire file with:

```tsx
import Image from 'next/image';
import { getAdsForSlot } from '../lib/server-data';
import { getAdFrame } from '../lib/ads';

export default async function AdBanner({ slot, className = 'my-8' }: Readonly<{ slot: string; className?: string }>) {
  const ad = await getAdsForSlot(slot);
  if (!ad) return null;

  const frame = getAdFrame(ad.frame);
  const box = `block border border-rule/60 bg-white overflow-hidden ${frame.maxWidth} mx-auto`;

  return (
    <div className={className}>
      <p className="text-[10px] uppercase tracking-[0.2em] text-ink/40 mb-1.5 font-medium">
        જાહેરાત / Advertisement
      </p>
      {ad.link_url ? (
        <a href={ad.link_url} target="_blank" rel="noopener noreferrer" className={box}>
          <div className={`relative w-full ${frame.aspect}`}>
            <Image src={ad.image_url} alt={ad.title} fill className="object-cover" sizes="(max-width: 768px) 100vw, 1600px" />
          </div>
        </a>
      ) : (
        <div className={box}>
          <div className={`relative w-full ${frame.aspect}`}>
            <Image src={ad.image_url} alt={ad.title} fill className="object-cover" sizes="(max-width: 768px) 100vw, 1600px" />
          </div>
        </div>
      )}
    </div>
  );
}
```

Notes:
- The `relative w-full ${frame.aspect}` div is the fixed-aspect box; `fill` + `object-cover` crops the image to it.
- `mx-auto` in `box` centers non-banner frames (`maxWidth` non-empty). Banner's `maxWidth` is `''` → full width of the slot container.
- No component tests exist in this repo (no test renderer); the frame lookup logic is already covered by `getAdFrame` tests in Task 1. Verify by typecheck + lint + manual render.
